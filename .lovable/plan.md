# Alpha STEM Academy visual refinement

## Goal
Restyle the existing website as a colorful, welcoming space-adventure STEM experience while keeping it parent-friendly and preserving all existing page copy, sections, images, branding, and behavior.

## Work
- Evolve the existing semantic color and surface tokens into the supplied space palette; refine existing buttons, cards, backgrounds, and subtle motion without changing content.
- Add the generated space-sticker illustration as restrained, decorative artwork within existing page layouts; keep it responsive and hidden from assistive technology.
- Finish the outstanding whole-site audit fixes: repair program-section deep links, point Alpha+ programme CTAs to the Alpha+ page, and complete per-page SEO/social metadata without replacing supplied copy.
- Verify routes, links, form behavior, keyboard-accessible mobile navigation, image loading, and layout at mobile, tablet, laptop, and desktop widths.

## Technical details
- Preserve TanStack Start, current assets and form behavior; no new dependencies, routes, sections, or integrations.
- Use existing semantic design tokens and reduced-motion support. Keep decorative artwork non-interactive and non-obstructive.
